# CLAUDE.md

Guia minima para Claude Code en JobIT-platform.

Claude Code debe seguir siempre las reglas de [AGENTS.md](AGENTS.md). Este archivo solo anade notas especificas para su uso en este repositorio.

## Notas especificas

- Usar `AGENTS.md` como fuente principal de reglas del proyecto.
- Consultar `docs/agents/` como biblioteca neutral de prompts, plantillas, checklists y skills documentales.
- Trabajar con cambios pequenos y revisables.
- No crear `.claude/skills/`, hooks, settings ni permisos automaticos sin una tarea explicita.
- No implementar codigo sin spec aprobada y revision humana.
