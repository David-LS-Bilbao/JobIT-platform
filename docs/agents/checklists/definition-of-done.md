# Checklist: Definition of Done

- [ ] La rama activa es la esperada.
- [ ] El cambio respeta la spec o task brief.
- [ ] Solo se tocaron archivos permitidos.
- [ ] El alcance no se amplio sin aprobacion.
- [ ] Los criterios de aceptacion estan cubiertos.
- [ ] La documentacion necesaria esta actualizada.
- [ ] No se introdujeron secretos.
- [ ] No se crearon archivos tecnicos fuera de alcance.
- [ ] Se ejecutaron las verificaciones indicadas.
- [ ] El resumen final incluye cambios, pruebas, riesgos y siguiente paso.
