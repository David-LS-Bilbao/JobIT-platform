# Checklist: Pre-Merge

- [ ] `git status --short` revisado.
- [ ] `git diff --stat` revisado.
- [ ] El diff contiene solo cambios esperados.
- [ ] No hay archivos generados accidentalmente.
- [ ] No hay cambios en `main` ni `dev` directamente.
- [ ] Se ejecutaron tests, lint o verificaciones aplicables.
- [ ] La documentacion refleja el estado real.
- [ ] La revision humana esta completada.
- [ ] El PR describe objetivo, alcance, verificaciones y riesgos.
