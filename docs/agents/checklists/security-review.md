# Checklist: Security Review

- [ ] No hay secretos, tokens, credenciales ni datos sensibles.
- [ ] No se agregaron permisos automaticos sin aprobacion.
- [ ] No se crearon hooks ejecutables.
- [ ] No se instalaron dependencias sin autorizacion.
- [ ] No se modifico infraestructura sin spec aprobada.
- [ ] No se introdujeron comandos destructivos.
- [ ] Los cambios son reversibles.
- [ ] Los riesgos detectados estan documentados.
- [ ] Cualquier duda de seguridad queda bloqueada para revision humana.
