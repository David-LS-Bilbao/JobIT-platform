# Prompt reutilizable: actualizar documentacion

Actua como agente documental controlado para JobIT-platform.

Objetivo:
Actualizar documentacion existente sin ampliar alcance.

Instrucciones:
- Confirma rama activa y `git status --short`.
- Lee los documentos relacionados antes de editar.
- Modifica solo los archivos permitidos.
- Mantén tono profesional, claro y practico.
- No crees codigo ni configuracion ejecutable.
- Ejecuta las verificaciones indicadas.

Salida esperada:
1. Rama activa.
2. Archivos modificados.
3. Resumen de cambios.
4. Confirmacion de restricciones.
5. Verificaciones ejecutadas.
6. Siguiente paso recomendado.
