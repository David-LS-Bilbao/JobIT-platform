# Conceptos para agentes IA

## Agent skill

Documento reutilizable que describe como ejecutar un tipo de tarea con objetivo, entradas, restricciones, checklist y salida esperada.

## Instrucciones globales

Reglas generales que aplican a cualquier trabajo con agentes, como idioma, seguridad, alcance y estilo de colaboracion.

## Instrucciones de proyecto

Reglas propias de JobIT-platform. Se centralizan en `AGENTS.md` y se complementan con esta biblioteca documental.

## Prompts reutilizables

Instrucciones preparadas para pedir a un agente una tarea comun, como crear una spec, revisar un diff o actualizar documentacion.

## Task brief

Documento breve que convierte una spec aprobada en una tarea concreta con archivos permitidos, restricciones y verificaciones.

## Checklist

Lista de comprobaciones para reducir errores antes de cerrar una tarea, revisar seguridad o preparar un merge.

## Spec

Documento de especificacion que define problema, alcance, fuera de alcance, criterios de aceptacion, riesgos y verificaciones.

## Revision humana

Validacion realizada por una persona antes de aprobar cambios, ampliar alcance o fusionar una rama.
